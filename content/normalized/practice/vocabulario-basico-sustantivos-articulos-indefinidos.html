Indefinite articles

In Spanish, indefinite articles agree with the noun in gender and number. Un and una usually mean a or an; unos and unas often mean some.

GenderSingularPlural
Masculineun librounos libros
Feminineuna casaunas casas

Notice the difference: el libro = the book; un libro = a book. In Spanish, plural nouns can also appear without an article: Tengo libros = I have books.

Singular and plural

Masculine: un → unos

un gato → unos gatos — a cat → some cats

un reloj → unos relojes — a watch → some watches

Feminine: una → unas

una mesa → unas mesas — a table → some tables

una luz → unas luces — a light → some lights

For common plurals, add -s after a vowel (casa → casas) and -es after many consonants (papel → papeles). For words ending in -z, change z → c before -es (luz → luces).

Examples in context

Un / Una

Tengo un libro en la mochila. — I have a book in my backpack.

Hay una mesa en la cocina. — There is a table in the kitchen.

Mi hermana tiene un gato. — My sister has a cat.

Necesito una ventana para esta habitación. — I need a window for this room.

Unos / Unas

Compré unos libros ayer. — I bought some books yesterday.

Hay unas flores en la mesa. — There are some flowers on the table.

Veo unos animales en el parque. — I see some animals in the park.

Necesitamos unas sillas para la reunión. — We need some chairs for the meeting.
