Articles + nouns + adjectives

In Spanish, articles and adjectives agree with the noun in gender (masculine or feminine) and number (singular or plural). Descriptive adjectives usually come after the noun.

FormDefiniteIndefinite
Masculine singularel libro rojoun libro rojo
Feminine singularla casa rojauna casa roja
Masculine plurallos libros rojosunos libros rojos
Feminine plurallas casas rojasunas casas rojas

El / la / los / las = the. Un / una = a/an. Unos / unas = some.

Agreement

-o / -a / -os / -as

un gato negro → una gata negra — a black male cat → a black female cat

los gatos negros → las gatas negras — the black male cats → the black female cats

Adjectives ending in -e

un libro interesante → una historia interesante — an interesting book → an interesting story

unos libros interesantes → unas historias interesantes — some interesting books → some interesting stories

Adjectives ending in a consonant

un ejercicio fácil → unos ejercicios fáciles — an easy exercise → some easy exercises

The adjective changes to match the noun. With ser, agreement still applies: La casa es bonita; Las casas son bonitas.

Examples in context

Definite articles: el, la, los, las

el libro rojo — the red book

la casa blanca — the white house

los zapatos nuevos — the new shoes

las mesas pequeñas — the small tables

Indefinite articles: un, una, unos, unas

un gato pequeño — a small cat

una ciudad bonita — a pretty city

unos relojes caros — some expensive watches

unas flores rojas — some red flowers

Adjectives with the same masculine and feminine form

el libro interesante — the interesting book

una película interesante — an interesting movie

los ejercicios fáciles — the easy exercises

unas preguntas fáciles — some easy questions
